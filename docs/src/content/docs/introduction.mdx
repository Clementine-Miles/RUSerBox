Server Box is an Android app for monitoring and managing Linux, Unix, and Windows servers.

## What is Server Box?

There are two ways to connect to a server: **SSH**, or a **[Monitor](/docs/advanced/monitor-agent/)** running on the server. SSH requires no additional server software and provides terminal, SFTP, and port-forwarding features. The Monitor is useful when opening an SSH port is inconvenient. It also stores monitoring history continuously, so charts can include data collected before the App connects.

The same server can use SSH and Monitor at the same time. The App tries them in the configured order and can fall back to the other connection. Features from both connections remain available.

## Key features

- **Real-time monitoring**: View CPU, memory, disk usage, network speed, GPU status, and system temperature
- **SSH terminal**: Connect through SSH with multiple tabs and a customizable appearance
- **SFTP client**: Browse and manage server files
- **Container management**: Manage Docker and Podman containers
- **Process management**: View and manage system processes
- **Systemd services**: Start, stop, and monitor systemd services
- **Network tools**: Run iPerf, ping, and Wake-on-LAN (WoL)
- **Snippets**: Save and execute custom shell commands

## Supported platforms

The client runs on Android.
