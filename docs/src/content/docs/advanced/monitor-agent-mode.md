---
title: Monitor agent mode
---

The Android app can open Agent mode tasks hosted by a configured Monitor agent.
Use the Agent screen to select a connected Monitor server, start a task and review command requests. The agent continues running a task when the phone disconnects.

Administrators can configure providers and permissions through the authenticated Monitor API. Configuration routes include `/api/v1/agent/settings`, `/api/v1/agent/permissions` and `/api/v1/agent/mcp`.
