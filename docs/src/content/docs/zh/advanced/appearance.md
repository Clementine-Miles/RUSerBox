---
title: 外观
description: 选择 Gruvbox 配色、图标和终端字体。
---

打开**设置 → 应用 → 外观**，选择 **Gruvbox Material** 或 **Gruvbox**。两种配色都支持浅色和深色模式。选择**自动**可跟随 Android 系统设置。Classic 和 MingCute 图标样式可独立选择。

在**设置 → 终端**中可以调整字体、字号、行高和终端亮度。默认字体是 Hack Nerd Font，另有 JetBrains Mono、Fira Code、Iosevka 和 Cascadia Code 可离线使用。在**设置 → 关于 → 许可证**中可查看许可声明。
