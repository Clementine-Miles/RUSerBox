---
title: 隐私政策
description: RUSerBox 保存哪些数据、发送哪些数据，以及发送给谁
---

最后更新：2026-11-27。

RUSerBox 是连接你所配置服务器的客户端。它没有用户账号，开发者也不运营任何中转 SSH、SFTP 或 Monitor 流量的服务：连接会从 App 直接发往你设置的地址。

## 设备上保存的数据

| 数据 | 位置 |
|---|---|
| 服务器（地址、用户名、SSH 密码、Monitor 密码与固定证书）、私钥及其密码、代码片段、端口转发、已信任的主机密钥、连接记录、设置 | 一个加密的 SQLite 数据库（`store.db`，ChaCha20-Poly1305）。其密钥由保存在 Android Keystore 中、不会离开 Keystore 的密钥封装。 |
| 桌面小部件的服务器列表和只读 Monitor token | App 私有的 preferences；token 使用 Keystore 密钥加密。 |

App 关闭了 Android 的云备份和设备迁移：没有 Keystore 密钥，数据库无法在其他设备上打开。

## 发送哪些数据，发送给谁

| 连接 | 目标 | 时机 |
|---|---|---|
| SSH（终端、状态、文件、转发） | 你配置的服务器和跳板机 | 你连接时，或服务器设置为自动连接时 |
| Monitor API | 你配置的 Monitor 地址 | 连接使用 Monitor 的服务器时，以及小部件刷新时 |

除此之外不发送任何数据：没有统计、没有崩溃报告、没有更新检查，也不会向开发者发起请求。App 没有 AI 功能。

## 删除数据

删除服务器会同时删除它的已信任主机密钥和连接记录。卸载 App 会删除它保存的所有数据。
